# AGENTS.md

## Purpose
Reminder for Codex on how to collaborate in this repo.

## Do
- Discuss first when requested; no file changes or commands unless explicitly asked.
- Ask for concrete examples when a classification/labeling issue is reported.
- Keep changes scoped and consistent across all related pages/scripts.
- Prefer config-driven fixes before code changes when thresholds are the intent.
- Summarize tradeoffs clearly before proposing edits.

## Avoid
- Making changes when the user says "don’t act, just discuss".
- Editing generated files unless explicitly requested.
- Diverging logic between `Insights`, `Index`, and `AuthorDetail` pages.
- Introducing new dependencies without approval.
- Using destructive commands unless explicitly requested.
